# Programming-and-Algorithm-Lab-Coursework--TFBOYS
The repository to submit our group's Programming and Algorithm Lab Coursework.
In our project,we have three input files:
1. comment.csv:the file store the comment to be analyzed ,the file name can be edited into any name and the file format supports both csv and txt.
2. toxicwords.txt:the file stores the toxic words we searched.
3. stopwords.txt:the file stores the stopwords we searched.
And 3 output files:
1.Programming CourseWork.exe(the interface)
2.analysis_report.txt(the file storing the result of the word analyze)
3.temp_processed.txt(used to support both txt and csv file for comment file)
And a reflective report:COMP1028 Project reflective report-TFBOYS.docx
And our code:Programming CourseWork.c

To use the user interface of our project,please put the three input files and a .c file and a exe file in the same folder.Then you can open the exe file directly to use the interface .
If you want to compile the code ,please use Visual Studio Code(the one we use to execute).  
Then click "Run"-->"Run without debugging"(or "Run and Debug" directly).
After using the user interface, you may get two other files(or the new version of these two files):
1.analysis_report.txt(generated after you choose to load the input file and then choose to output the analyze result)
2.temp_processed.txt(the one used when loading the comment file,generated after you choose to load the file.)
